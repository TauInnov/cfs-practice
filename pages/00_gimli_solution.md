# פתרון: 0. גימלי, יולי 1983

**התשובה: כ-10,117 ק"ג דלק בהמראה**, פחות ממחצית מ-22,300 הק"ג שנדרשו.

## שלב אחר שלב

הצוות כפל את הליטרים במקדם 1.77 והניח שהתוצאה בקילוגרמים:

```python
crew_kg = fuel_in_tanks_L * factor_used     # 13,597 "kg" according to the crew
```

את ההפרש עד 22,300 הוא המיר חזרה לליטרים, באותו מקדם:

```python
added_L = (required_kg - crew_kg) / factor_used   # 4,917 liters added
total_L = fuel_in_tanks_L + added_L               # 12,599 liters at takeoff
```

המסה האמיתית מתקבלת מהצפיפות של הדלק:

```python
fuel_kg = total_L * density                      # about 10,117 kg
```

## מה השתבש

המקדם 1.77 ממיר ליטרים ל**ליברות** (פאונד), לא לקילוגרמים. ה-22,300 שהצוות חשב שהגיע אליהם היו 22,300 ליברות, כ-45% מהדלק הנדרש. לא הופיעה שום שגיאה: כל המספרים בחישוב היו תקינים, רק היחידה הייתה שגויה.

## תשובות שגויות נפוצות

- **22,300:** הנחה שהחישוב של הצוות נכון, בלי להמיר בעזרת הצפיפות.
- **12,599:** עצירה בליטרים, בלי להמיר למסה.

## למי שסיים

`fuel_kg / required_kg` נותן כ-0.45. ליברה אחת היא כ-0.4536 ק"ג, ואכן `1.77 * 0.4536` הוא כ-0.803: הצפיפות של הדלק בק"ג לליטר.
