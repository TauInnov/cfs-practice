# פתרון: 2. מאדים, ספטמבר 1999

<p><a href="../board.html?round=mars">→ חזרה ללוח התשובות</a></p>

**התשובה: הדחף האמיתי היה גדול פי 4.45 מזה שתוכנת הניווט הניחה.**

## הנתונים

הפרמטרים מתא הנתונים בעמוד, שעליהם מבוססות כל השורות בהמשך:

```python
logged = 100.0          # the number in the file for this burn
mass = 600.0            # spacecraft mass (kg)
delta_v = 0.7413703     # velocity change measured by tracking (m/s)

# common units of force, in newtons
KGF_TO_N = 9.80665      # kilogram-force
LBF_TO_N = 4.448222     # pound-force
DYNE_TO_N = 1e-5        # dyne
```

## שלב אחר שלב

הסעיפים כאן זהים לסעיפי העמוד. סעיף 1 הוא מה שקרה בפועל, סעיף 2 הוא מה שתוכנת הניווט הניחה, וסעיפים 3 ו-4 משווים ביניהם.

**1. הדחף האמיתי.** דחף הוא מסה כפול שינוי המהירות שנמדד במעקב:

```python
impulse_real = mass * delta_v              # 444.8 N*s
```

**2. הדחף שהניחה תוכנת הניווט.** היא קראה את המספר שבקובץ, 100, כאילו הוא ב-N·s:

```python
impulse_assumed = logged                   # 100.0 N*s
```

**3. היחס.** זו התשובה שמגישים:

```python
factor = impulse_real / impulse_assumed    # about 4.448
```

**4. איזו יחידה מסבירה את היחס.** משווים את היחס לערך של כל יחידת כוח בניוטון:

```python
abs(factor - KGF_TO_N) < 0.01              # False
abs(factor - LBF_TO_N) < 0.01              # True
abs(factor - DYNE_TO_N) < 0.01             # False
```

## מה השתבש

היחס הוא בדיוק המעבר מפאונד-כוח לניוטון: הקובץ נכתב ב-lbf·s ונקרא כ-N·s. שני הצדדים עבדו עם `float` תקין, ולמספר עצמו אין יחידה, ולכן שום בדיקה בתוכנה לא יכלה לזהות את הפער.

## תשובות שגויות נפוצות

- **0.225:** יחס הפוך, הדחף שהניחה התוכנה חלקי הדחף האמיתי (סעיף 3).
- **445:** הדחף האמיתי עצמו, ולא היחס (סעיף 1).

## למי שסיים

בכל תיקון החללית קיבלה דחף גדול מזה שתוכנת הניווט רשמה. ההפרש הצטבר לאורך המסע, כך שהמסלול בפועל סטה מהמסלול שחושב בקרקע, והחללית הגיעה למאדים נמוך בהרבה מהמתוכנן.
