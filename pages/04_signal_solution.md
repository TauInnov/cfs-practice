# פתרון: 4. אות רדיו, 1977

<p><a href="../board.html?round=signal">→ חזרה ללוח התשובות</a></p>

**התשובה: `WOW!`**

## הנתונים

הפרמטרים מתא הנתונים בעמוד, שעליהם מבוססות כל השורות בהמשך:

```python
signal = "01010111010011110101011100100001"   # the received bits
```

## שלב אחר שלב

הסעיפים כאן זהים לסעיפי העמוד. סעיפים 2 עד 4 מפענחים תו אחד, וסעיף 5 את ההודעה כולה.

**1. כמה ביטים וכמה תווים.** 8 ביטים לתו:

```python
len(signal)                     # 32 bits
len(signal) // 8                # 4 characters
```

**2. הבית הראשון.** חיתוך 8 ביטים:

```python
first = signal[0:8]             # "01010111"
```

**3. מהמחרוזת למספר.** `int(..., 2)` קורא מחרוזת של ביטים כמספר בבסיס 2:

```python
value = int(first, 2)           # 87
```

**4. מהמספר לתו.** `chr` מחזיר את התו שמתאים למספר בטבלת ASCII:

```python
chr(value)                      # "W"
```

**5. כל ההודעה.** אותו דבר לשלושת הבתים האחרים, וחיבור למחרוזת אחת:

```python
message = (chr(int(signal[0:8], 2)) + chr(int(signal[8:16], 2))
           + chr(int(signal[16:24], 2)) + chr(int(signal[24:32], 2)))   # "WOW!"
```

## מה עומד מאחורי זה

במחשב כל תו נשמר כמספר, וכל מספר נשמר כביטים. החזרות בסעיף 5 הן סימן לכך שאפשר לכתוב את זה בלולאה.

## תשובות שגויות נפוצות

- **`W`:** פענוח של הבית הראשון בלבד (סעיף 4).
- **`87`:** עצירה במספר, בלי להמיר לתו (סעיף 3).

## למי שסיים

הרצף השני מפוענח ל-`HDUWK`. הזזה של כל תו 3 מקומות אחורה, `chr(ord(c) - 3)` לכל תו, נותנת **`EARTH`**.
