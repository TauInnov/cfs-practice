# פתרון: 3. אומואמואה, אוקטובר 2017

<p><a href="../board.html?round=oumuamua">→ חזרה ללוח התשובות</a></p>

**התשובה:** כ-`26.3` קילומטרים לשנייה. זו המהירות שבה הגיעה אומואמואה מהחלל הבין-כוכבי, ושבה היא מתרחקת ממנו בחזרה.

## הנתונים

הפרמטרים מתא הנתונים בעמוד, שעליהם מבוססות כל השורות בהמשך:

```python
GM_sun = 1.327e11     # the Sun's G*M (km^3/s^2)
AU = 1.496e8          # one astronomical unit (km)

# distance from the Sun (AU), speed relative to the Sun (km/s), made by humans?
r1, v1, art1 = 1.0, 29.78, False      # Earth
r2, v2, art2 = 0.586, 54.55, False    # Halley's comet at perihelion
r3, v3, art3 = 121, 17.0, True        # Voyager 1, 2012
r4, v4, art4 = 0.256, 87.3, False     # 'Oumuamua at perihelion, September 2017
```

## שלב אחר שלב

הסעיפים כאן זהים לסעיפי העמוד. סעיפים 1 ו-2 בודקים אילו גופים קשורים, סעיף 3 מזהה את הגוף הבין-כוכבי, וסעיפים 4 ו-5 מחשבים את המהירות.

**1. מהירות המילוט.** `GM_sun` נתון בקילומטרים, ולכן ממירים את המרחק מיחידות אסטרונומיות לקילומטרים:

```python
def escape_speed(r_au):
    return (2 * GM_sun / (r_au * AU)) ** 0.5

escape_speed(1.0)    # about 42.1 km/s
```

**2. קשור או לא.** הביטוי הבוליאני עצמו הוא התשובה:

```python
def is_bound(r_au, v):
    return v < escape_speed(r_au)

b1 = is_bound(r1, v1)    # True:  29.78 < 42.12
b2 = is_bound(r2, v2)    # True:  54.55 < 55.02, barely
b3 = is_bound(r3, v3)    # False: 17.0 > 3.83
b4 = is_bound(r4, v4)    # False: 87.3 > 83.25
```

**3. הגוף הבין-כוכבי.** שני גופים אינם קשורים, אבל אחד מהם מעשה ידי אדם:

```python
def is_interstellar(r_au, v, artificial):
    return not is_bound(r_au, v) and not artificial

is_interstellar(r1, v1, art1)    # False
is_interstellar(r2, v2, art2)    # False
is_interstellar(r3, v3, art3)    # False: unbound, but made by humans
is_interstellar(r4, v4, art4)    # True: 'Oumuamua
```

**4. המהירות הרחק מהשמש.** הפונקציה קוראת לשתי הפונקציות הקודמות, ובכל מסלול יש `return`:

```python
def v_infinity(r_au, v):
    if is_bound(r_au, v):
        return 0.0
    else:
        return (v**2 - escape_speed(r_au)**2) ** 0.5
```

**5. התשובה.** זו התשובה שמגישים:

```python
v_inf = round(v_infinity(r4, v4), 1)    # 26.3 (km/s)
```

## מה עומד מאחורי זה

במסלול סגור, כמו של כדור הארץ או של השביט של האלי, האנרגיה הכוללת (קינטית ועוד פוטנציאלית) שלילית, והגוף חוזר שוב ושוב. אומואמואה הגיעה עם אנרגיה חיובית: הרחק מהשמש נעה כבר במהירות של כ-26 קילומטרים לשנייה, השמש האיצה אותה ל-87 בנקודת הקירבה, והיא ממשיכה החוצה ותאט חזרה לאותם 26. מסלולה היפרבולי, ואין כוח שיכול להחזיר אותה. המהירות הזאת דומה למהירויות של כוכבים בסביבת השמש ביחס אליה, וזו עוד ראיה שהגוף הגיע מחוץ למערכת השמש.

## תשובות שגויות נפוצות

- **0.0:** המרחק לא הומר לקילומטרים (סעיף 1). מהירות המילוט יוצאת עצומה, כל הגופים נראים קשורים, ו-`v_infinity` מחזירה `0.0`.
- **87.3:** המהירות בנקודת הקירבה, בלי להחסיר את מהירות המילוט (סעיף 4).
- **64.5:** חסר הגורם 2 במהירות המילוט. $\sqrt{GM/r}$ היא מהירות של מסלול מעגלי, לא מהירות המילוט.
- **691.4:** $v_\infty^2$ במקום $v_\infty$, בלי השורש (סעיף 4).
- **16.6:** Voyager 1. הפונקציה בסעיף 3 בדקה רק אם הגוף אינו קשור, בלי `not artificial`.

## למי שסיים

`escape_speed(r2) / v2` הוא כ-1.0087: לשביט של האלי חסרים פחות מאחוז אחד ממהירותו כדי להימלט. Voyager 1 אינה קשורה לשמש בזכות מעברים ליד צדק ושבתאי: בכל מעבר כזה כוח המשיכה של כוכב הלכת שינה את מהירותה ביחס לשמש והגדיל אותה. בתרגיל הזנחנו את כוכבי הלכת, ובמקרה שלה הם בדיוק מה שהופך אותה ללא קשורה.
