# פתרון: 1. דהראן, פברואר 1991

<p><a href="../board.html?round=dhahran">→ חזרה ללוח התשובות</a></p>

**התשובה: התחזית הייתה שגויה בכ-575 מטרים.**

## הנתונים

הפרמטרים מתא הנתונים בעמוד, שעליהם מבוססות כל השורות בהמשך:

```python
tick_design = 0.1                      # time step the clock was designed to count (s)
tick_register = 0.09999990463256836    # time step actually stored in the register (s)
uptime_hours = 100                     # continuous operation before the attack (h)
v_scud = 1676                          # Scud speed (m/s)
```

## שלב אחר שלב

הסעיפים כאן זהים לסעיפי העמוד. סעיפים 1 עד 3 עוסקים בשעון, וסעיף 4 בתחזית.

**1. שגיאת השעון בצעד בודד.** הערך 0.1 נשמר ברגיסטר בקירוב, ולכן בכל צעד השעון "מפסיד" חלק זעיר משנייה:

```python
err_tick = tick_design - tick_register     # about 9.5e-08 s per tick
```

**2. מספר הצעדים ב-100 שעות.** עשרה צעדים בשנייה, 3,600 שניות בשעה:

```python
n_ticks = uptime_hours * 3600 * 10         # 3,600,000 ticks
```

**3. שגיאת הזמן המצטברת.** שגיאת הצעד הבודד כפול מספר הצעדים:

```python
clock_err = err_tick * n_ticks              # about 0.343 s
```

**4. שגיאת התחזית.** המערכת חישבה את מיקום ה-Scud לפי הזמן של השעון, אבל ה-Scud נע לפי הזמן האמיתי. במהלך שגיאת הזמן הוא עבר:

```python
miss_m = clock_err * v_scud                 # about 575 m
```

## מה השתבש

שגיאה של עשירית מיליונית השנייה בכל צעד אינה מורגשת, אבל היא מצטברת עם כל צעד. אחרי 100 שעות היא הגיעה לשליש שנייה, ובמהירות של Scud זה מספיק כדי שהמטרה לא תימצא באזור החזוי.

## תשובות שגויות נפוצות

- **57.5:** שכחו שיש 10 צעדים בשנייה (סעיף 2).
- **0.343:** עצרו בשגיאת הזמן, בלי לכפול במהירות (סעיף 4).

## למי שסיים

אחרי 8 שעות השגיאה היא כ-0.027 שניות, כ-46 מטרים. אחרי 20 שעות כ-0.069 שניות, כ-115 מטרים. השגיאה גדלה ליניארית עם זמן הפעולה, ולכן אתחול תקופתי של המערכת מאפס אותה.
