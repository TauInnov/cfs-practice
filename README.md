# תרגול כיתה: מחשבים לפיזיקאים

בכל סבב נפתח כאן עמוד חדש. כשהמתרגל מודיע על סבב חדש, רעננו את הדף.

**איך עובדים**

1. לחצו על **Open in Colab** ליד העמוד של הסבב.
2. הריצו את התא הראשון בעמוד (תא ההגדרות).
3. פתרו בזוגות והגישו את התשובה בתא ההגשה.

להרצה ב-Colab צריך חשבון Google. בלי חשבון: לחצו על **הורדה**, פתחו את הקובץ ב-Jupyter במחשב (Anaconda), או עבדו על המחשב של בן או בת הזוג.
