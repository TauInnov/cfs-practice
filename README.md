# cfs-practice

In-class practice pages for *Computers for Physics* (TAU).

**Students:** open the book at https://tauinnov.github.io/cfs-practice/

**TAs:** to release a page, upload its notebook into `pages/` (Add file → Upload files → Commit).
The Action rebuilds the table of contents from the files in `pages/` and publishes the book in about 2–3 minutes.
Deleting a file from `pages/` removes it from the book the same way.
